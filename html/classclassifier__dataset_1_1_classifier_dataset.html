Detailed Description

PyTorch Dataset for processed protein classification data.

Handles feature/label extraction, supports production (inference) mode, and provides access to accession IDs.

Parameters
processed_dfpandas DataFrame with all processed features and labels.
feature_colsList of column names to include as features (default: all columns except label_col).
label_colName of the label column (default: 'label').
balance_colName of the balance column for stratification (optional).
productionIf True, assumes no labels (for classifying new data).
accession_idsOptional list/array of protein IDs.

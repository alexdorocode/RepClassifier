config_utils.merge_dicts ( * dicts)

Merge multiple dictionaries into one, handling nested dictionaries.

If a key exists in multiple dictionaries, the value from the last dictionary will be used. If a key's value is a dictionary in multiple dictionaries, they will be merged recursively. If the merged dictionary exceeds 1000 keys, a message will be printed.

Parameters
dictsVariable number of dictionaries to merge.
Returns
Merged dictionary.

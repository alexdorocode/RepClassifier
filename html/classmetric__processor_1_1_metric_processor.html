Detailed Description

Processes and normalizes metric columns in a DataFrame.

Handles NaN strategies, scaling, and optional row trimming based on config.

Parameters
dfInput pandas DataFrame.
metric_colsList of metric column names to process.
nan_strategyStrategy for handling NaNs ("drop", "fill_mean", "fill_zero", "fill_minus_one").
scalerScaling method ("standard" or "minmax").
trim_configOptional list of dicts for row trimming (each with 'column', 'min', 'max').
